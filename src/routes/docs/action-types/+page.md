description: "Overview of the action types in Customer Actions for Jira and how to configure each one for your customer portal."
---

Customer Actions for Jira provides multiple pre-configured action types to use right away on your portal.

The following is a selection of currently available action types:

![Action Types](/docs/action-types.png)

Click on a box to receive more information about this action as well as basic configuration options.

In most cases, the only thing necessary to create an action is a label. After entering some text you will be able to create the action and see the corresponding configuration screen.
