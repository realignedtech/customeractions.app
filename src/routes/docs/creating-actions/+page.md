---
title: "Creating Actions"
description: "How to create a customer action in Jira Service Management: find the project settings, add an action, and choose an action type."
---

In order to create actions, you will need project administrator permissions for the Jira Service Management (JSM) project.

Navigate to a JSM project. This is the only supported project type. You will not be able to use the app with Jira Software or Jira Work Management. Click on "Project Settings" in the lower left-hand corner.

![Project Settings Location](/docs/project-settings.png)

Now scroll down on the left hand side and look for "Customer Actions".

![Customer Actions in Project Settings](/docs/project-settings2.png)

You will now see a prompt to create your first customer actions.

![Create Action, Step 1](/docs/create-action1.png)

After clicking "Add Action" you will have a choice of several action types, which are explained in the next chapter.

Click on the left hand side "[Action Types](/docs/action-types)" to expand the menu and see the examples.
